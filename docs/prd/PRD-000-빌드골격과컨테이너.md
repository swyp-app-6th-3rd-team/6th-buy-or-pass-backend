# PRD-000 — 빌드 골격과 컨테이너

**상태**: 완료

## 무엇을 왜

Spring Boot 4 · JDK 25 · MySQL · QueryDSL 이 **실제로 함께 도는지**부터 확정한다.

이 조합에서 QueryDSL 이 가장 위험한 가정이었다. 본가 `com.querydsl` 은 5.1.0 에서 정체되어
Hibernate 7(= Boot 4)을 지원하지 않는다. 여기서 실패하면 나머지 요구사항을 아무리 잘 만들어도
빌드 첫 단계에서 무너지므로 **가장 먼저** 검증한다.

## 범위

**포함**
- `build.gradle` — Boot 4.1.0, JDK 25 toolchain, OpenFeign QueryDSL 7.5
- `../../docker-compose-dev.yml` — MySQL 8.4, `.env` 분리, healthcheck, named volume
- Flyway 마이그레이션 — Sakila 스키마(V1) · 인증 테이블(V2) · 시드(별도 location)
- `Dockerfile` — 멀티스테이지, non-root 실행

**제외**
- 애플리케이션 코드 (PRD-001 이후)
- CI 파이프라인 (PRD-004)

## 열린 질문 → 해소됨

- **본가 QueryDSL 을 쓸 수 있나?** → 아니오. Hibernate 7 미지원. [ADR-0002](../adr/0002-openfeign-querydsl.md)
- **Sakila 원본을 그대로 넣을 수 있나?** → 아니오. 6가지가 깨진다. [ADR-0005](../adr/0005-sakila-schema-modifications.md)

## 발견한 문제

| 문제 | 원인 | 조치 |
|---|---|---|
| `ERROR 1824: Failed to open the referenced table 'city'` | 테이블 알파벳 순 + `staff`↔`store` 순환 FK | `SET FOREIGN_KEY_CHECKS = 0 → 1` 로 감쌈 |
| 시드 적재 시 FK 위반 | `staff` 가 `store` 보다 먼저 INSERT 됨 | 원본의 `ALTER TABLE` teardown 을 `FOREIGN_KEY_CHECKS` 로 대체 |
| `film_text` 가 비어 있음 | 원본은 트리거로 채우는데 트리거를 제외함 | 시드 끝에 백필 SQL 추가 |
