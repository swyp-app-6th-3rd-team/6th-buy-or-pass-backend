# 요청사항

이 템플릿이 충족해야 할 조건.

1. JDK 25 · Spring Boot 4 · MySQL · JPA · QueryDSL · Lombok · TestContainers
2. docker-compose 로 구성 (온프레미스 홈서버 배포 전제)
3. GitHub PR 템플릿
4. OAuth2 소셜 로그인
5. JWT 인증
6. Sakila 데이터베이스 기반 JPA Entity 및 Repository
7. DDD 차용
